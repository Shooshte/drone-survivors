# DRO-41 — Catalog combination validation

Scope comes from the approved DRO-22 isolated-arena work and its final child
DRO-41. Validate the existing seven enemy kinds, directional fields/repair site,
six modules and twelve temporary upgrades. Campaign introduction and human
acceptance remain gated; no campaign save, shop, spawn or offer changes.

Add one selectable **Combined catalog** scenario after the fourteen existing
scenarios. It uses the existing environment and three seven-kind waves at 1,
16 and 31 seconds, under the existing 30-enemy cap and 60-second default duration.
All existing warning, resource, reset and preview behavior remains in use.
A new scenario is preferable to silently increasing difficulty in existing
focused practice scenarios. An offline-only custom encounter would not let a
human reproduce the comparison from the selector.

Compare unupgraded and four-card builds, single-module controls, and contrasting
routes using the production catalog installation at fixed 30 Hz. Use the normal
selector and preview choices. Explicitly disclose preview XP, synthetic input,
any controlled micro-fixture setup, and timing limitations. Do not assert that
all builds must win or manufacture a balance change: adjust only demonstrated
dominance, redundancy or defects, with before/after evidence.

Native validation covers the combined scenario setup, four-card preview,
active HUD, restart and return at 1120×720 and 640×480, plus existing detailed
mechanic fixtures as needed. Check text bounds and inspect captures. Document
measured outcomes, each enemy response, module roles, twelve upgrade tradeoffs,
and outstanding human checks in docs/playtests.md and a focused evidence file.
